# PrivacyFirst Photo Organizer — support

Bug reports and feature requests for **[PrivacyFirst Photo Organizer](https://itfanatic.com/image-organizer)**.

This repository holds **no source code**. It exists so you can file something, watch it, and see
when it is fixed — which a support email cannot do.

## Where to go

## ⚠️ Do not post personal data here

Every issue in this repository is **public and permanently indexed**. Before you press submit:

- **Never attach your `.lic` licence file.** It contains your name and email address, and it is
  what unlocks the software. If you have lost it, email support@itfanatic.com and it will be
  re-sent.
- **Never post your order reference, email address, or postal address.**
- **Check your screenshots.** The app shows your photos, your folder paths, and the names you
  have given to people. Crop or blur anything you would not put on a postcard — a face, a file
  path with your name in it, a location.
- **Data protection requests** (a copy of your data, correction, or erasure) must go to
  support@itfanatic.com. They contain personal data by definition and must not be filed publicly.

## What helps a bug report get fixed

The application never sends us anything — no telemetry, no crash reports, no analytics. So what
you write in the issue is genuinely all there is to go on. The template asks for the useful
things: your operating system, the version from **About**, what you did, and what happened
instead.

## Licence and support scope

The software is commercial and its source is not public. Filing an issue does not entitle you to
a fix, and there is no service-level agreement — but this is read by the person who wrote the
software, and a clear reproduction is usually acted on.
